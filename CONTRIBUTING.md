# Contributing

Thank you for your interest in contributing! Please feel free to put up a PR for any issue or feature request.
Even if you have little to no experience with React, I'll be more than happy to help. :)

## Setup

1. Fork the repo
2. Clone your fork
3. Make a branch for your feature or bug fix
4. Install Node.js 22.12 or newer, then run `npm ci`
5. Run `npm run dev` and open `http://localhost:4200` in a browser
6. Work your magic (read [MIGRATION.md](MIGRATION.md) for the architecture, SCSS scoping rules and conventions)
7. Make sure nothing is broken:
    - `npm run lint && npm run format:check && npm run typecheck && npm test`
    - `npm run build` (the only step that compiles the SCSS)
    - `npm run e2e` (Playwright against the production build; run `npx playwright install chromium` once)
8. To test service worker changes: `npm run build && npm run preview` and open `http://localhost:4173`
   (the service worker is only generated by the production build)
9. Add yourself to the [contributor's list](https://github.com/hdjirdeh/angular2-hn#contributors) in the README!
10. Commit your changes and reference the issue you're addressing (for example: `git commit -am 'Commit message. Closes #5'`)
11. Push your branch to your fork
12. Create a pull request from your branch on your fork to `master` on this repo
13. Have your branch get merged in! :star2:

If you experience a problem at any point, please don't hesitate to file an issue or send me a message!
