# React HN

React 18 + TypeScript + Vite port of the Angular 9 Hacker News client in `../src`. The migration is
incremental — see [`../docs/MIGRATION.md`](../docs/MIGRATION.md) for the component manifest and status.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm test         # Vitest + React Testing Library
npm run lint
```
