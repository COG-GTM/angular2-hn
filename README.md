## React port

The app has been migrated to React 18 + TypeScript + Vite + React Router v6. The React app lives in
[`react/`](/react) and is a feature-parity port of the Angular app; the Angular sources at the repo root are kept
buildable alongside it.

```
cd react
npm install
npm run dev        # dev server on http://localhost:4200
npm run build      # type-check + production build into react/dist/
npm run preview    # serve the production build on http://localhost:4173
npm run lint       # eslint, zero warnings tolerated
```

The service worker is generated by [`vite-plugin-pwa`](https://vite-pwa-org.netlify.app/) and, like the Angular
`ServiceWorkerModule` before it, is **only active in production builds** — so offline behaviour has to be exercised
through `npm run build && npm run preview`, not `npm run dev`.

Note: both dev servers default to port 4200, so run only one at a time (or pass `--port`).

## Build process (Angular)

Note: This project has been ejected (with AOT + production settings) in order to customize Webpack configurations.

 - Clone or download the repo
 - `npm install`
 - `npm start` to run the application with webpack-dev-server or `npm build` to kick off a fresh build and update the output directory (`dist/`)

Note: modern Node.js versions need `NODE_OPTIONS=--openssl-legacy-provider` for the Angular build and dev server.

Note: Any Service Worker changes will not be reflected when you run the application locally in development. To test service worker changes:
 - `npm build`
 - `npm run precache` to generate the service worker file
 - `npm run static-serve` to load the application along with the service worker asset using [live-server](https://github.com/tapio/live-server)
