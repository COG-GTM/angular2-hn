## Offline Support

This app uses [Workbox](https://workboxjs.org/) to generate a service worker as part of the build step to load quickly and work offline.

## Build process

The app is built with React, TypeScript and Vite (Node 20+).

 - Clone or download the repo
 - `npm install`
 - `npm run dev` to start the dev server on `localhost:5173`
 - `npm run lint`, `npm run typecheck` and `npm test` to check changes
 - `npm run build` to create a production build in `dist/` (including the service worker generated by `vite-plugin-pwa`)
 - `npm run preview` to serve the production build locally, which is the way to test service worker changes
