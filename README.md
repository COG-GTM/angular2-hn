<p align="center">
  A progressive Hacker News client built with React
</p>

---

:zap: **Fast:** Service Worker precaching + runtime API caching (Workbox via `vite-plugin-pwa`) for fast loads with and without a network.

:iphone: **Responsive:** Completely responsive UI that can be installed to your mobile home screen to provide a native feel.

:rocket: **Progressive:** Installable PWA with offline support.

## Stack

| | |
|---|---|
| UI | React 18 + TypeScript |
| Build | Vite 5 |
| Routing | React Router v6 |
| Data | `@tanstack/react-query` over the [node-hnapi](https://github.com/cheeaun/node-hnapi) REST API |
| Styling | SCSS + CSS Modules |
| PWA | `vite-plugin-pwa` (Workbox) |
| Tests | Vitest + React Testing Library |

> This app was migrated from Angular 9 to React. The application lives in [`react-app/`](./react-app).

## Project layout

```
react-app/
  public/            static assets, icons and favicon
  src/
    api/             HackerNews REST client (plain fetch, promise based)
    components/
      core/          Header, Footer, Settings modal
      feeds/         Feed page and Item row
      item-details/  Item page and the recursive Comment tree
      shared/        Loader and ErrorMessage
      user/          User profile page
    context/         SettingsContext (theme, fonts, spacing, link behaviour)
    hooks/           useFeed / useItem / useUser React Query hooks
    models/          shared TypeScript types
    styles/          global styles and the theme engine
    utils/           small helpers ported from Angular pipes
  App.tsx            app shell + routes
```

## Offline Support

The service worker is generated at build time by `vite-plugin-pwa`. The app shell is precached and
Hacker News API responses are cached at runtime with a `NetworkFirst` strategy.

## Manifest

The Web App Manifest is generated by `vite-plugin-pwa`, allowing the app to be installed to the home
screen on Chromium based browsers.

## Themes

Built in theme engine!

Current themes:
* Default
* Night
* Black (AMOLED)

The theme follows the operating system's `prefers-color-scheme` until an explicit choice is made in
the settings modal, which is then persisted to `localStorage`.

## Build process

```
cd react-app
npm install
npm run dev        # development server
npm run build      # type-check + production build into react-app/dist
npm run preview    # serve the production build (service worker included)
npm test           # Vitest unit tests
```

Note: the service worker is only generated for production builds, so use `npm run build && npm run preview`
to test offline behaviour.
