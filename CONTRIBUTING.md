# Contributing

Thank you for your interest in contributing! Please feel free to put up a PR for any issue or feature request.
Even if you have little to no experience with React, I'll be more than happy to help. :)

## Setup

1. Fork the repo
2. Clone your fork
3. Make a branch for your feature or bug fix
4. `npm install` (Node 20+; this installs the dependencies of the `react/` app)
5. Run `npm start` and open `localhost:5173` in a browser
6. Work your magic in `react/src`
7. Run `npm run lint`, `npm run typecheck` and `npm test` — new components should come with Vitest + React Testing Library tests
8. Run `npm run build` to kick off a production build and make sure nothing is broken
9. To test service worker / PWA changes:
  * `npm run build` to produce `react/dist/` (the Workbox service worker is generated by `vite-plugin-pwa`)
  * `npm run preview` to serve the production build with the service worker registered
10. Run `npm run e2e` to execute the Playwright end-to-end suite (`npx playwright install chromium` the first time)
11. Add yourself to the [contributor's list](https://github.com/hdjirdeh/angular2-hn#contributors) in the README!
12. Commit your changes and reference the issue you're addressing (for example: `git commit -am 'Commit message. Closes #5'`)
13. Push your branch to your fork
14. Create a pull request from your branch on your fork to `master` on this repo
15. Have your branch get merged in! :star2:

If you experience a problem at any point, please don't hesitate to file an issue or send me a message!
