## Build process

The app is built with [Vite](https://vitejs.dev/), React 18 and TypeScript. Styles are the original Sass files, kept 1:1 so the React app renders pixel-identically to the Angular version.

 - Clone or download the repo
 - Node.js `^20.19.0 || >=22.12.0` (required by Vite 7; enforced via `engines` in `package.json`)
 - `npm install`
 - `npm run dev` to run the application with the Vite dev server on `http://localhost:5173`
 - `npm run build` to type-check and produce a production build in `dist/` (includes the service worker and web manifest, generated by `vite-plugin-pwa`)
 - `npm run preview` to serve the production build locally (the service worker only runs against the built output)
 - `npm run lint` / `npm run typecheck`

### Pixel parity with the Angular app

`parity/run-parity.mjs` drives the legacy Angular app and the React app side by side with Playwright, serving both the same recorded API responses from `parity/fixtures/`, and compares full-page screenshots (pixelmatch) plus the computed styles of every element at desktop and mobile widths.

 - Run the Angular app from the `master` branch (`npm start` in a separate checkout, defaults to `http://127.0.0.1:4200`)
 - Run this app with `npm run dev` (`http://127.0.0.1:5173`)
 - `npm run parity` (override with `OLD_URL`, `NEW_URL`, `CHROME_PATH`, or `ONLY=<regex>` to run a subset of scenarios)
 - Results are written to `parity/report/` (`REPORT.md`, `index.html` with side-by-side screenshots, and `results.json`)
